What is going on

You try to open your .QBW file and QuickBooks refuses. The message is often an error in the 6000 series, such as 6000 -82 or 6000 -305, or error 6150 or 6123. Your books are stuck behind it.

The first thing to find out is whether the problem is the file or the program.

What usually causes it

  • The company file itself is damaged, often after a crash, a power loss or a dropped network connection.
  • The file lives on a network drive and the hosting setup is wrong or the connection is unreliable.
  • The file sits in a folder with a very long path or odd permissions.
  • The file grew very large and began to fail on read.

What to do first

  1. Copy the company file and its folder before you try anything.
  2. Open a sample company file that comes with QuickBooks. If that fails too, the program install is the problem, not your file.
  3. If the sample opens, copy your file to the local computer and try it from there.
  4. Try the Verify Data and Rebuild Data utilities on the copy. If they fail, send me a sample.
